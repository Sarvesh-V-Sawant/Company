## 5. Firebase Initialization Pattern

`lib/main.dart:22`:
```dart
await Firebase.initializeApp();
```

`lib/main.dart:14` (background handler):
```dart
await Firebase.initializeApp();
```

Both calls use **native config mode** (no `options:` argument). This is valid — Flutter Firebase reads from `google-services.json` (Android) and `GoogleService-Info.plist` (iOS) at runtime. No dependency on `firebase_options.dart` at runtime.

However, `flutterfire configure` generates `firebase_options.dart` AND wires the Gradle plugin. After running it, `main.dart` should be updated to pass explicit options:

```dart
import 'firebase_options.dart';

await Firebase.initializeApp(
  options: DefaultFirebaseOptions.currentPlatform,
);
```

This is the recommended pattern for `firebase_core ^3.x` — explicit options prevent misconfiguration across environments.

## 7. Required Commands

Run all commands from `apps/mobile/` directory. Run sequentially.

### Step 1 — Install FlutterFire CLI (if not installed)

```powershell
dart pub global activate flutterfire_cli
```

Verify:
```powershell

```

### Step 2 — Run flutterfire configure

```powershell
flutterfire configure --project=<firebase-project-id>
```

Replace `<firebase-project-id>` with the Firebase project ID (visible in Firebase Console → Project Settings → General → Project ID).

**What this does:**
- Reads `android/app/google-services.json` and `ios/Runner/GoogleService-Info.plist`
- Validates that `applicationId` (`com.genesis.system`) matches the Android app registered in the Firebase project
- Validates that bundle identifier (`com.genesis.system`) matches the iOS app registered
- Generates `lib/firebase_options.dart`
- Patches `android/app/build.gradle.kts` to apply `com.google.gms.google-services` plugin
- Patches `android/build.gradle.kts` if needed

**Expected output:**
```
✓ Firebase android app com.genesis.system registered.
✓ Firebase ios app com.genesis.system registered.
✓ Firebase configuration file lib/firebase_options.dart generated successfully.
```

**If package name mismatch:** Firebase Console → Project Settings → Your apps → verify registered Android app package name is `com.genesis.system` and iOS bundle ID is `com.genesis.system`. If registered under old name, add new apps in Firebase Console first.
