## H1 Fix Verification

**Scenario verified by U-REG-07 (updated test):**

1. Employee checks in Monday 9:00 AM (IST) — session created with `isActive: true`
2. Employee forgets to check out
3. Midnight: `autoCloseSessions` cron runs — session now `isActive: false, closedBySystem: true, systemCloseReason: 'midnight-rollover'`
4. Tuesday: Employee submits `forgotCheckOut` regularization for Monday
5. Admin approves
6. `approve()` queries: `{ $or: [{ isActive: true }, { isActive: false, closedBySystem: true, systemCloseReason: 'midnight-rollover' }] }` → finds Monday's midnight-rolled session ✅
7. Updates session: `durationMinutes = requestedCheckOut - checkIn.timestamp`, `systemCloseReason = 'admin-force-close'`, checkout filled in ✅
8. `reconcileForSession` sums all closed sessions → `computeDayStatus` → `AttendanceDay.status` updated ✅
9. `overtimeMinutes` computed as `max(0, totalMinutes - requiredDailyMinutes)` ✅
