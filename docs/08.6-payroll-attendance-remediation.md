**Add** canonical day status derivation note to §11 constraints:

```
Day Status Derivation (canonical — all engines must follow this order):

1. durationStatus:
   totalMinutes >= requiredDailyMinutes  → 'present'
   totalMinutes >= halfDayThresholdMinutes → 'half-day'
   else                                  → 'absent'

2. lateArrivalCapStatus:
   checkIn.timestamp >= halfDayLateCheckInTime → 'half-day'
   else                                        → no cap

3. finalStatus = worst(durationStatus, lateArrivalCapStatus)
   Priority: 'absent' > 'half-day' > 'present'

Payroll impact: both duration-based and late-arrival half-days count in halfDays.
effectivePresentDays = presentDays + halfDays × 0.5
```

**Add/replace** in `PayrollSummarySchema`:

```typescript
grossSalary:             { type: Number, required: true, min: 0 },
perDaySalary:            { type: Number, required: true, min: 0 },
halfDays:                { type: Number, required: true, default: 0, min: 0 },
manualDeduction:         { type: Number, required: true, default: 0, min: 0 },
manualDeductionRemark:   { type: String, default: '' },
deductionBreakdown: {
  lwpDeduction:          { type: Number, required: true, min: 0 },
  absentDeduction:       { type: Number, required: true, min: 0 },
  manualDeduction:       { type: Number, required: true, default: 0, min: 0 },
  totalDeductions:       { type: Number, required: true, min: 0 },
},
netSalary:               { type: Number, required: true, min: 0 },
```

**Replace** canonical formula note in §12:

```
Canonical Payroll Formula (v2 — Decision 2):

effectivePresentDays = presentDays + halfDays × 0.5
perDaySalary         = grossSalary / effectiveWorkingDays
lwpDeduction         = effectiveLwpDays × perDaySalary
absentDeduction      = absentDays × perDaySalary
attendanceDeduction  = lwpDeduction + absentDeduction
totalDeductions      = attendanceDeduction + manualDeduction
netSalary            = Math.round(Math.max(0, grossSalary - totalDeductions) × 100) / 100

Explicitly excluded (v1 — by design):
Basic %, HRA %, PF, ESI, Professional Tax, Bonus components.
Document as: "Salary Components: Out of scope v1. System uses flat gross salary."
```

### docs/04-api-specification.md — New endpoint §8.6

```
PATCH /api/v1/payroll/:id/:yearMonth/adjust
Auth:   Admin
Guard:  payroll status must be 'draft' — returns 409 if 'finalised'
```

```json
{
  "manualDeduction": 500,
```
