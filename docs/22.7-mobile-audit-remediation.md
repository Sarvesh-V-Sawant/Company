## Findings Resolved

### Firebase Initialization — RESOLVED

`lib/main.dart` previously called `Firebase.initializeApp()` without options at two locations. Both now use explicit options:

```dart
import 'firebase_options.dart';

// Background handler (line 14):
await Firebase.initializeApp(options: DefaultFirebaseOptions.currentPlatform);

// main() (line 22):
await Firebase.initializeApp(options: DefaultFirebaseOptions.currentPlatform);
```

`DefaultFirebaseOptions.currentPlatform` reads the correct configuration per platform (Android vs iOS) from the generated `firebase_options.dart`. This is the recommended pattern for `firebase_core ^3.x` and prevents misconfiguration across environments.
