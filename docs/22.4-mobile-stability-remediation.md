### C2 — RESOLVED
12 imports across 10 test files (`test/`). All `package:company_mobile/` references replaced with `package:genesis_workforce/` to match the updated `pubspec.yaml` package name. Root cause: branding agent searched only `lib/` (all relative imports — clean) and missed `test/`.

### H1 — RESOLVED

### H2 — RESOLVED
