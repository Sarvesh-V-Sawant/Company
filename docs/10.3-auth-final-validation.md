| M2 | **BR-AUTH-21/22 ordering** — `confirmPasswordReset` checks token expiry before hash comparison. Spec requires hash comparison first (BR-AUTH-21), then expiry (BR-AUTH-22). ### LOW — Remaining: 2

| # | Finding | Location | Notes |
|---|---|---|---|
| L1 | **`revokedReason: 'logout'` on password-change revocation** — `changePassword()` uses `'logout'` when revoking all sessions. Misleading in audit trail. `RevokedReason` type would need a new `'password-change'` variant. | `src/services/AuthService.ts:297` | Misleading audit data; no security impact |
| L2 | **`hashIpAddress` fallback key** — `hashIpAddress()` uses `process.env.JWT_SECRET ?? 'fallback'`. If `JWT_SECRET` is undefined, IP PII hashes use a known literal key. Should guard against missing secret. | `src/lib/utils/hash.ts:9` | Only affects misconfigured environments where `JWT_SECRET` is absent — `jwtVerify` would also fail at that point |
