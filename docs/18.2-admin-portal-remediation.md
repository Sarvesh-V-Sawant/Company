## Resolution Summary

### H-09 — Middleware / Role Guard / Maintenance Mode

**Resolution:** Restored route protection via `src/proxy.ts` (the Next.js 16 equivalent of `middleware.ts`).

**Changes:**
- `src/proxy.ts` — Added role guard (`payload.role !== 'admin'` → redirect `/unauthorized`) and maintenance mode (`MAINTENANCE_MODE=true` → rewrite to `/maintenance.html`)
- `src/app/unauthorized/page.tsx` — Created full branded Access Denied page with "Contact administrator" + "Sign in with another account" actions
- `public/maintenance.html` — Created static maintenance page with 30s auto-refresh

**Note:** `src/middleware.ts` was also created initially but deleted when build revealed Next.js 16 uses `proxy.ts` exclusively — both cannot coexist.
