## Deployment Prerequisites

Before releasing to end users:

1. **`google-services.json`** — Place at `android/app/google-services.json`. Obtain from Firebase console. Required for FCM at runtime.
2. **Device fingerprint alignment** — Admin-registered device hashes must use 4-field formula (`id|model|brand|serialNumber`). Existing 3-field hashes require device re-registration.
3. **API base URL** — Set via `--dart-define=API_BASE_URL=https://your-api.com` at build time.
